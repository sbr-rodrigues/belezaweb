🌸 Dicas da Afrodite — Página Web de Inscrição

Este repositório apresenta uma página HTML desenvolvida para promover a Semana de Beleza — Dicas da Afrodite, uma iniciativa voltada para jovens que desejam aprimorar seus cuidados pessoais, elevar a autoestima e explorar sua beleza autêntica.

A página inclui uma apresentação visual elegante, cronograma de oficinas, galeria de imagens, formulário completo de inscrição e elementos multimídia — tudo estruturado em HTML e CSS, com foco em organização, usabilidade e estilo.

✨ Funcionalidades

Design minimalista e feminino, inspirado em temas de beleza e autocuidado.

Site totalmente responsivo, utilizando HTML sem frameworks.

Imagens e vídeo integrados para enriquecer a experiência do usuário.

Formulário completo de inscrição, incluindo:

Campos de texto

E-mail, senha e idade

Seleção de cursos (radio buttons)

Checkboxes de interesses

Dropdown “Como soube sobre nós?”

Campo de biografia

Validações básicas em inputs como idade, e-mail e senha.

Organização limpa com pastas separadas para CSS e mídia.

🚀 Como Visualizar o Projeto

Baixe ou clone este repositório:

git clone https://github.com/sbr-rodrigues/belezaweb.git


Certifique-se de que a pasta media e o arquivo style.css estejam no mesmo nível do index.html.

Abra o arquivo index.html em qualquer navegador moderno.

🎯 Objetivo do Projeto

Criar uma página bonita e funcional para apresentar uma semana temática de oficinas de beleza, oferecendo uma experiência visual amigável e um formulário completo para inscrições.
